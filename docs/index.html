New Balance Shop

Інтернет-магазин спортивного одягу та взуття на ASP.NET Core. Технічна документація проєкту.

Документація коду

Публічні класи, інтерфейси та методи з XML-коментарів. Згенеровано DocFX, є пошук і навігація.

Документація ендпоінтів

HTTP API: запити, відповіді, моделі. Scalar на основі специфікації OpenAPI.

Живий сайт

Задеплоєний фронтенд на Vercel: каталог, кошик, замовлення.
