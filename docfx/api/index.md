# Довідник API (код)

Автоматично згенерована документація публічних класів, інтерфейсів і методів з XML-коментарів вихідного коду. Простори імен відповідають шарам Clean Architecture:

- `NewBalanceShop.Domain` — сутності та контракти репозиторіїв
- `NewBalanceShop.Application` — сервіси, DTO, мапери
- `NewBalanceShop.Infrastructure` — EF Core, репозиторії
- `NewBalanceShop.Presentation.Controllers` — REST-контролери

Документація HTTP-ендпоінтів лежить окремо: <a href="../../api/index.html">Scalar</a>.
