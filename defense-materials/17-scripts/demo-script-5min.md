# Сценарій демо (5 хвилин) на живому сайті

Живий сайт: https://newbalance.cc.cd. Два сценарії, які просив викладач: 1) реєстрація й логін нового користувача, 2) адмін-панель для модератора. Пароль адміністратора тут не записано: брати з особистих нотаток (email адміна: `admin@newbalanceshop.com`).

## Підготовка (за 10 хвилин до захисту)

1. **Розбудити сервер.** Безкоштовний Render засинає, перший запит може тривати до 50 секунд. Відкрити в окремій вкладці: https://newbalanceshop-api.onrender.com/api/Categories (має повернути JSON із трьома категоріями). Потім відкрити https://newbalance.cc.cd і переконатися, що каталог завантажився.
2. Вкладки наперед: сайт, документація API (https://vicitmceo.github.io/NewBalanceShop/), Jira-дошка.
3. Вийти з акаунта на сайті, мова UA. Придумати email для нового користувача заздалегідь, наприклад `demo.<число>@example.com`, і пароль від 8 символів.
4. Запасний варіант, якщо інтернет або сервер підведуть: слайди 14-17 презентації й скріни в `16-live-ui-screenshots`.

| 0:50 | Відкрити картку товару, обрати розмір, «В кошик». Лічильник у шапці. | Кошик зберігається на сервері в сесії, навіть для гостя. |

## Сценарій 2: адмін-панель для модератора (2:00)

| Хв | Дія | Що казати |
|---|---|---|
| 0:00 | Вийти, увійти як адміністратор (пароль з нотаток; на екрані не показувати). | Адмін має роль IsAdmin, пароль у репозиторії лише як хеш. |
| 0:15 | Меню акаунта: з'явився пункт «Адмін-панель» і бейдж «Адміністратор». Відкрити `/admin`. | Сторінка доступна лише адміну. Без входу сервер повертає 401, звичайному покупцеві 403. |
| 0:30 | Вкладка «Користувачі». Показати кнопки «Заблокувати» і «Видалити». Тестового користувача з першого сценарію заблокувати, потім розблокувати. | Блокування, видалення з підтвердженням. Користувача із замовленнями видалити не можна. Увага: у таблиці email реальних людей, показувати швидко, без наближення. |
| 1:00 | Вкладка «Товари»: «Редагувати» будь-який товар, змінити ціну чи залишок, зберегти (або скасувати). | Додати, змінити, видалити: ціна, стара ціна, стать, тип, залишок, розміри, фото. Запис товарів дозволено лише адміну. |
| 1:25 | Вкладка «Замовлення»: показати список і випадаючий статус. | Статуси: New, Confirmed, Shipped, Delivered, Cancelled. |
| 1:45 | Видалити тестового користувача з першого сценарію («Видалити», підтвердити). Вийти. | Прибираємо за собою, на проді тестових даних не залишаємо. |

## Після демо (0:30)

Показати документацію API (Scalar на GitHub Pages) і, якщо питають про безпеку, https://newbalance.cc.cd у DevTools, вкладка Network: заголовки CSP, X-Frame-Options, nosniff.

## Якщо щось пішло не так

- Каталог довго вантажиться: сервер ще прокидається. Почекати до хвилини, поки пояснюєте архітектуру; не оновлювати сторінку.
- Реєстрація: «email уже зареєстрований». Взяти інший email.
- Забули пароль адміна: показати слайд 17 (адмін-панель) і скріни.
- Не показувати в публічних записах пароль, токени й email реальних користувачів.
