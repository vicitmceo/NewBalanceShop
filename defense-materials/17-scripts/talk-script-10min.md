## Чесні відповіді на ймовірні запитання

- **Чому в Git майже всі коміти від одного автора?** Описати реальний розподіл роботи й внесок Team Lead (планування, Jira, документи) своїми словами. У Git його внесок не видно.
- **Чому немає форм входу й адмін-панелі у фронтенді?** Бекенд-API готовий і задокументований, інтерфейс форм у плані; на демо показуємо через Swagger.
- **Чому ID покупця передається параметром?** Це тимчасове рішення для анонімного кошика (FR-08); у плані брати його з сесії.
- **Чому немає CI та DocFX?** Не встигли, у беклозі.
