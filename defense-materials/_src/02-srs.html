Нефункціональні вимоги (NFR)

  • Продуктивність: читання через AsNoTracking, DTO замість сутностей.
  • Масштабованість: Clean Architecture, окремі проєкти, stateless-сервіси з DI.
  • Безпека: хеш паролів PBKDF2, ролі на адмін-ендпоінтах (401/403), customerId із сесії, білий список CORS, rate limiting.
  • Надійність: міграції EF Core, 219 автотестів, покриття 91,1%.
  • Зручність: інтерфейс UA/EN/FR, адаптивна верстка, кошик без обов'язкової реєстрації.
